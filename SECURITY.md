

# Security Policy

## Supported Versions

This project is currently under active development. Security updates are provided for the latest version only.

| Version | Supported |
| ------- | --------- |
| Latest  | :white_check_mark: |
| Older versions | :x: |

## Reporting a Vulnerability

Please report security vulnerabilities privately by emailing:

**m.d.s.chamath@gmail.com , navindujanith2004@gmail.com**

Do not report vulnerabilities through public GitHub issues.

Include:

- A clear description of the vulnerability
- Steps to reproduce it
- Possible security impact
- Screenshots or proof of concept, if available

You can expect an initial response within 3 business days. We will investigate the report, provide updates during the review, and notify you when the issue has been fixed or declined.

Accepted vulnerabilities will be fixed in a future security update. Reporters will be credited unless they request anonymity.
